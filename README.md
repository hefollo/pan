## 项目介绍

彩虹外链网盘是一款基于 PHP 开发的网盘与外链分享程序，支持多种类型文件上传，并可生成对应的外链地址，适用于文件分享、图床、音视频外链等多种使用场景。

本项目是在开源版本基础上进行二次开发与界面美化的版本，保留了原有核心功能，并对前后台主题风格、交互体验和部分功能展示进行了优化。

## 主要功能

- 支持所有常见格式文件上传
- 支持生成文件外链、图片外链、音乐外链、视频外链
- 生成外链时可同时生成对应的 UBB 代码和 HTML 代码
- 支持文本、图片、音乐、视频在线预览
- 支持 TXT 等文本内容在线查看
- 支持文件内容在线编辑
- 在线编辑支持以下格式：
  `txt`、`text`、`log`、`md`、`markdown`、`json`、`js`、`mjs`、`css`、`less`、`scss`、`html`、`htm`、`xml`、`svg`、`csv`、`ini`、`conf`、`config`、`yaml`、`yml`、`sql`、`vue`、`ts`、`tsx`、`jsx`
- 可作为网盘使用，也可作为图床或音乐在线试听网站使用
- 支持对接多种云存储服务
- 支持图片违规检测功能

## 支持的云存储

新版本支持对接以下云存储平台：

- 阿里云 OSS
- 腾讯云 COS
- 华为云 OBS
- 又拍云
- 七牛云
- 通用 S3 兼容存储

通用 S3 使用 AWS Signature Version 4 签名协议，可用于 AWS S3、MinIO、Cloudflare R2、Backblaze B2，以及其他兼容 S3 API 的对象存储服务。

### 通用 S3 配置

进入后台的“存储类型设置”，展开“通用 S3 兼容存储”，填写以下参数：

| 配置项 | 说明 |
| --- | --- |
| Access Key | 对象存储平台提供的访问密钥 ID |
| Secret Key | 对象存储平台提供的访问密钥密码 |
| Endpoint | S3 API 地址，需填写完整的 `http://` 或 `https://` 地址 |
| Region | Bucket 所在区域，例如 `us-east-1`；Cloudflare R2 通常填写 `auto` |
| Bucket | 存储桶名称 |
| 对象前缀 | 文件在 Bucket 内的目录前缀，默认是 `file/`；留空则使用根目录 |
| 地址风格 | 可选择虚拟主机风格 `bucket.endpoint` 或路径风格 `endpoint/bucket` |

常见配置提示：

- AWS S3：Endpoint 可填写对应区域的 S3 地址，Region 必须与 Bucket 实际区域一致。
- MinIO：填写 MinIO API 地址和端口，通常选择“路径风格”。
- Cloudflare R2：Endpoint 通常为 `https://<账户ID>.r2.cloudflarestorage.com`，Region 填写 `auto`。
- Backblaze B2：填写平台提供的 S3 Endpoint，并使用该 Endpoint 对应的 Region。
- 如果平台报 Bucket、域名或签名不匹配，可切换“地址风格”后重试。

通用 S3 支持网站中转上传、POST Policy 浏览器直传、签名下载、断点下载、文件删除和文件信息读取。使用浏览器直传前，需要确认存储平台支持 S3 POST Policy，并为 Bucket 配置允许本站域名发起 `POST` 请求的 CORS 规则；部分 S3 兼容平台不支持这种直传方式，此时请在后台选择“网站中转”。服务器还需启用 PHP cURL 扩展。

> S3 Signature V4 会将请求域名纳入签名。启用签名下载时，链接会使用 S3 配置中的 Endpoint，不能在签名生成后直接替换成其他下载域名。

## 项目说明

本项目为基于开源程序的二开美化版本，主要包含：

- 前台界面样式优化
- 后台管理界面美化
- 外观主题扩展
- 新增外观设置功能，可在后台切换多套前后台联动主题风格
- 新增广告公告位设置功能，可在后台统一管理顶部公告、广告位内容及展示方式
- 新增用户管理与权限设置功能，可区分普通/高级用户；高级用户在未单独限制时不受全站每日上传数量限制，也可为每位用户单独设置文件大小、每日上传数量和权限有效期，并支持封禁、解封、查看用户文件及删除用户
- 新增在线查看文本内容功能
- 新增在线编辑功能
- 在线编辑白名单已扩展，适合文本、前端代码、配置文件和部分脚本文件直接在线修改
- 新增通用 S3 兼容存储，可对接 AWS S3、MinIO、Cloudflare R2、Backblaze B2 等平台
- 部分功能体验调整与增强

## 二开与新增内容

相较于原版程序，本项目额外新增或强化了以下内容：

- 外观设置：
  后台新增外观设置页面，可切换不同站点主题，并同步作用于前台页面与后台管理界面，不再只是单独修改前台样式。

- 广告公告位设置：
  后台新增广告公告位设置页面，可自定义公告内容、广告位内容、广告类型、展示开关等，方便统一维护站点顶部公告与首页广告位。

- 在线查看与在线编辑：
  新增文本内容在线查看功能，并支持多种文本类、前端类、配置类文件在线编辑，方便直接在网页中快速处理文件内容。

- 通用 S3 存储：
  新增基于 Signature Version 4 的通用 S3 存储驱动，支持自定义 Endpoint、Region、Bucket、对象前缀和地址风格，并支持直传、签名下载及断点下载。

- 界面美化：
  对前台文件列表、上传页、文件查看页，以及后台管理界面进行了整体风格优化与主题适配增强。
