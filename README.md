## 项目介绍

彩虹外链网盘是一款基于 PHP 开发的网盘与外链分享程序，支持多种类型文件上传，并可生成对应的外链地址，适用于文件分享、图床、音视频外链等多种使用场景。

本项目是在开源版本基础上进行二次开发与界面美化的版本，保留了原有核心功能，并对前后台主题风格、交互体验和部分功能展示进行了优化。

## 主要功能

- 支持所有常见格式文件上传
- 支持生成文件外链、图片外链、音乐外链、视频外链
- 生成外链时可同时生成对应的 UBB 代码和 HTML 代码
- 支持文本、图片、音乐、视频在线预览
- 支持 TXT 等文本内容在线查看
- 支持文件内容在线编辑
- 在线编辑支持以下格式：
  `txt`、`text`、`log`、`md`、`markdown`、`json`、`js`、`mjs`、`css`、`less`、`scss`、`html`、`htm`、`xml`、`svg`、`csv`、`ini`、`conf`、`config`、`yaml`、`yml`、`sql`、`vue`、`ts`、`tsx`、`jsx`
- 支持覆盖上传，用新文件替换已有文件而对外链接保持不变
- 可作为网盘使用，也可作为图床或音乐在线试听网站使用
- 支持对接多种云存储服务
- 支持图片违规检测功能
- 支持违规文件公示，向访客公开已封禁文件的处理情况
- 支持覆盖记录审计，管理员可复查每一次内容替换

## 环境要求

- PHP >= 7.1，需启用 cURL 扩展
- MySQL / MariaDB
- 当前程序版本 `VERSION` 为 `1574`，数据库版本 `DB_VERSION` 为 `1009`

## 安装与升级

全新安装访问 `install/` 目录按提示完成即可。

从旧版本升级时，覆盖程序文件后**必须**访问一次：

```
http(s)://你的域名/install/update.php
```

看到“网站数据库升级完成”即可。升级脚本会建表、补齐配置项，并把历史数据迁移到新结构。若跳过这一步，程序会因为数据库版本落后而提示“请先完成网站升级”。

> 静态资源由 `VERSION` 常量做缓存串（`style.css?v=1574`）。如果自行修改了 CSS/JS，记得同步提高 `includes/common.php` 里的 `VERSION`，否则浏览器会继续使用旧缓存；站点前面挂了 CDN 的还需刷新 CDN。

## 访问链接机制

文件的对外链接使用独立的随机 `token`，与文件内容哈希分离。带来的效果：

- 同一份内容被多人上传时，每个人都会得到**独立的记录和独立的链接**，各自的文件名、密码、隐藏设置互不影响；物理文件仍然只存一份，不重复占用空间。
- 覆盖上传和在线编辑只会改变当前这一条记录指向的内容，**不会连带修改其他人的文件**。
- 删除文件时，只有当没有任何记录再引用这份内容时，才会真正清理物理文件。

## 支持的云存储

新版本支持对接以下云存储平台：

- 阿里云 OSS
- 腾讯云 COS
- 华为云 OBS
- 又拍云
- 七牛云
- 通用 S3 兼容存储

通用 S3 使用 AWS Signature Version 4 签名协议，可用于 AWS S3、MinIO、Cloudflare R2、Backblaze B2，以及其他兼容 S3 API 的对象存储服务。

### 通用 S3 配置

进入后台的“存储类型设置”，展开“通用 S3 兼容存储”，填写以下参数：

| 配置项 | 说明 |
| --- | --- |
| Access Key | 对象存储平台提供的访问密钥 ID |
| Secret Key | 对象存储平台提供的访问密钥密码 |
| Endpoint | S3 API 地址，需填写完整的 `http://` 或 `https://` 地址 |
| Region | Bucket 所在区域，例如 `us-east-1`；Cloudflare R2 通常填写 `auto` |
| Bucket | 存储桶名称 |
| 对象前缀 | 文件在 Bucket 内的目录前缀，默认是 `file/`；留空则使用根目录 |
| 地址风格 | 可选择虚拟主机风格 `bucket.endpoint` 或路径风格 `endpoint/bucket` |

常见配置提示：

- AWS S3：Endpoint 可填写对应区域的 S3 地址，Region 必须与 Bucket 实际区域一致。
- MinIO：填写 MinIO API 地址和端口，通常选择“路径风格”。
- Cloudflare R2：Endpoint 通常为 `https://<账户ID>.r2.cloudflarestorage.com`，Region 填写 `auto`。
- Backblaze B2：填写平台提供的 S3 Endpoint，并使用该 Endpoint 对应的 Region。
- 如果平台报 Bucket、域名或签名不匹配，可切换“地址风格”后重试。

通用 S3 支持网站中转上传、POST Policy 浏览器直传、签名下载、断点下载、文件删除和文件信息读取。使用浏览器直传前，需要确认存储平台支持 S3 POST Policy，并为 Bucket 配置允许本站域名发起 `POST` 请求的 CORS 规则；部分 S3 兼容平台不支持这种直传方式，此时请在后台选择“网站中转”。服务器还需启用 PHP cURL 扩展。

> S3 Signature V4 会将请求域名纳入签名。启用签名下载时，链接会使用 S3 配置中的 Endpoint，不能在签名生成后直接替换成其他下载域名。

## 外观主题

后台“系统设置 - 外观设置”可切换 **19 套**外观，前台页面、后台管理界面、顶部公告条、友链广告位、赞助页和各类弹窗会一起联动。

外观分成两类：**布局型**改的是页面结构（导航位置、内容排版），**配色型**只改颜色和质感、保持默认的顶部导航布局。

### 布局型外观（4 套）

| 外观 | 结构 | 后台 |
| --- | --- | --- |
| 控制台侧栏风 | 顶部导航变左侧固定侧栏，内容区为圆角卡片 | 同步改为侧栏 |
| 数据控制台风 | 更紧凑的侧栏，标题与搜索独立成顶栏，文件列表上方增加统计卡与类型筛选，侧栏底部显示今日上传进度 | 同步改为侧栏 |
| 上传门户风 | 居中的门户式顶部导航，首页增加大号上传引导区，文件列表改为卡片网格 | 只换配色，保留顶栏 |
| 深色工作台风 | 深色底 + 72px 图标导航条（鼠标移上去展开文字），文件列表按文件管理器排布，右侧常驻文件预览面板 | 同步改为侧栏 |

其中数据控制台风与深色工作台风在文件列表页会显示**类型筛选**标签（全部 / 图片 / 视频 / 文档 / 压缩包，对应 `?ft=` 参数），标签上的数量为站点级统计，带 5 分钟缓存。深色工作台风的预览面板点击列表行即可切换，展示文件大小、格式、上传时间、上传 IP 与外链地址，可直接复制链接。

## 违规文件公示

面向合规场景，把已封禁文件的处理情况对外公开。

- 前台入口在导航栏“违规公示”，地址 `/violation.php`
- 后台“文件管理”里**封禁**文件会自动生成公示记录，**解封**会自动撤下（记录仍保留在后台便于复查），批量操作同样生效
- 后台“系统设置 - 违规公示管理”可查看全部记录、修改文件名与备注、单条开关是否公示、手动补录，或彻底删除记录
- 装此功能前就已封禁的老文件，升级脚本会自动补录一次；之后也可用管理页右上角的【导入已封禁文件】重复补录，已有记录会自动跳过
- 后台“系统设置 - 网站信息设置”里可关闭整个公示功能，并自定义公示页顶部的说明文字

**隐私处理**：公示页只输出脱敏信息——文件名打码（保留首尾字符和扩展名）、IP 只显示前两段（如 `1.2.*.*`），不输出文件哈希、下载链接或任何可访问地址，避免公示页反过来成为违规内容的索引。

开启了云端图片检测时，机器自动命中封禁的文件会留档但**默认不公示**，需人工确认后手动放出，以免误判直接对外。

## 覆盖记录审计

用户的覆盖上传和在线编辑都会改变已有链接背后的内容，后台“覆盖记录”用于复查这类改动。

- 记录覆盖前后的文件名、大小、格式，图片可直接预览新内容
- 记录操作者 UID / IP、时间和方式（覆盖上传 / 在线编辑）
- 显示该文件当前状态（正常 / 待审 / 已封禁 / 已删除）
- 每条记录可直接查看、封禁、删除文件、标记已复查或删除记录
- 默认只显示未复查的条目，页面顶部提示积压数量，支持一键全部标记已复查

覆盖上传的新内容会重新走一遍图片检测，命中即自动封禁；已封禁的文件不允许被覆盖，也不允许上传者自行删除。

## 赞助页

- 赞助名单在后台“系统设置 - 赞助名单管理”维护
- 同一页面可配置微信、QQ 钱包、支付宝三张收款码的图片地址，支持完整网址或相对 `includes/sponsor/` 的路径；某一项留空则赞助页上不显示该收款方式
- 赞助页配色跟随站点当前外观主题

## 项目说明

本项目为基于开源程序的二开美化版本，主要包含：

- 前台界面样式优化
- 后台管理界面美化
- 外观扩展至 19 套（15 套配色型 + 4 套布局型），前后台、公告条、赞助页及弹窗联动
- 新增广告公告位设置功能，可在后台统一管理顶部公告、广告位内容及展示方式
- 新增用户管理与权限设置功能，可区分普通/高级用户；高级用户在未单独限制时不受全站每日上传数量限制，也可为每位用户单独设置文件大小、每日上传数量和权限有效期，并支持封禁、解封、查看用户文件及删除用户
- 新增在线查看文本内容功能
- 新增在线编辑功能，白名单已扩展，适合文本、前端代码、配置文件和部分脚本文件直接在线修改
- 新增覆盖上传功能及配套的后台审计界面
- 新增违规文件公示功能
- 新增通用 S3 兼容存储，可对接 AWS S3、MinIO、Cloudflare R2、Backblaze B2 等平台
- 文件访问链接改为独立 token，同内容多次上传互不干扰
- 部分功能体验调整与增强

## 二开与新增内容

相较于原版程序，本项目额外新增或强化了以下内容：

- **外观设置**：
  后台新增外观设置页面，可切换 19 套站点外观：15 套配色型覆盖浅色、深色与毛玻璃三类风格，4 套布局型进一步改变导航位置与内容排版。所选外观同步作用于前台页面、后台管理界面、公告条、赞助页以及 layer 弹窗和后台模态框，不再只是单独修改前台样式。

- **违规文件公示**：
  新增面向访客的公示页与后台公示管理，封禁/解封自动联动，公示内容经过脱敏处理。

- **覆盖上传与审计**：
  实现覆盖上传（替换内容而保持链接不变），并新增后台覆盖记录页，便于及时发现把正常文件换成违规内容的行为。

- **广告公告位设置**：
  后台新增广告公告位设置页面，可自定义公告内容、广告位内容、广告类型、展示开关等，方便统一维护站点顶部公告与首页广告位。

- **在线查看与在线编辑**：
  新增文本内容在线查看功能，并支持多种文本类、前端类、配置类文件在线编辑，方便直接在网页中快速处理文件内容。

- **通用 S3 存储**：
  新增基于 Signature Version 4 的通用 S3 存储驱动，支持自定义 Endpoint、Region、Bucket、对象前缀和地址风格，并支持直传、签名下载及断点下载。

- **界面美化**：
  对前台文件列表、上传页、文件查看页，以及后台管理界面进行了整体风格优化与主题适配增强。上传页重排为居中的拖拽区，带拖拽高亮反馈；文件列表按外观分别呈现为卡片表格、卡片网格或文件管理器式列表。

- **稳定性处理**：
  对外接口请求（快捷登录、IP 归属地）统一加了连接与总时长超时，避免对方接口不通时占满 PHP 进程拖垮站点；快捷登录失败后有短时冷却与明确的失败提示。布局型外观的统计查询带缓存，不会因为文件表没有对应索引而反复全表扫描。
