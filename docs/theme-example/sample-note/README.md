# 示例：便签风

主题开发文档 `docs/theme.md` 里的示例主题。继承内置外观「蓝白清爽」（cloud），演示了：

- `settings`：主色、纸张底色、圆角、背景纹理，在后台「外观设置」里调，样式表里用 `var(--theme-…)` 取；
- `blocks`：三张主题自带卡片——欢迎横幅（只在首页）、链接组（`lines` 配置项）、便签纸（容器）；
- `layouts/index.json`：首页默认布局，把欢迎横幅和链接组放在文件列表上面；
- `styles` / `admin_styles`：前台、后台各一个样式表；
- `preview`：外观列表里显示的预览图。

安装：把 `sample-note` 这个文件夹打成 zip（zip 里可以带这一层文件夹），在后台「外观设置 → 主题包」上传，然后在外观列表里选中「示例：便签风」保存。
