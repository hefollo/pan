# 截图目录

README.md 里引用的本地截图放在这里。按用途分成三块：本目录根下是外观和几张单独引用的图，
`前端截图/` 和 `后台截图/` 分别放前台和后台的页面截图，文件名就是 README 里的小标题。

**根目录**

| 文件名 | 内容 |
| --- | --- |
| `数据控制台风.png` | 布局型外观：数据控制台风 |
| `上传门户风.png` | 布局型外观：上传门户风 |
| `深色工作台风.png` | 布局型外观：深色工作台风 |
| `渐变仪表盘风.png` | 布局型外观：渐变仪表盘风 |
| `buy-page.png` | 前台「购买权限」页：套餐按分类分区展示、当前权限、侧栏权限卡 |
| `admin-pay-setting.png` | 后台「购买套餐设置」：通用设置 + 支付宝当面付/易支付标签页 |
| `admin-plan-list.png` | 后台套餐列表：分类、每日数量、单文件大小、有效期、上下架 |

**前端截图/**

登录界面、注册界面，以及个人中心的四个页签（`个人中心-概览`、`个人中心-我的文件`、
`个人中心-订单记录`、`个人中心-账号设置`）。

**后台截图/**

后台首页、文件管理、用户管理、覆盖记录、存储类型设置、内容检测设置、内容检测记录、
外观设置、购买套餐设置、订单记录、邮件发信设置、发信记录、用户IP地址获取设置。

新增截图时，把图片放进对应目录，然后在 README.md 里引用——注意**不要**写成本地相对路径
`img/目录/文件名.png`，那样图片只有在 GitHub 仓库页面里才能正常显示，README 内容被复制到
别的地方（博客、论坛、文档站）时全部会变成裂图。统一写成 GitHub 的 raw 绝对地址：

```
https://raw.githubusercontent.com/hefollo/pan/main/img/目录/文件名.png
```

文件名有中文或空格的话要做 URL 百分号编码（浏览器地址栏粘贴访问一次，复制出来的地址就是编码
好的），不能直接把中文糊在链接里。

建议截图统一用 PNG，宽度 1400px 左右，太大的话可以先压缩一下。
