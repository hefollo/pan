# 截图目录

README.md 里引用的本地截图放在这里，文件名对应关系如下（把截图另存成这些名字即可）：

| 文件名 | 内容 |
| --- | --- |
| `buy-page.png` | 前台「购买权限」页：套餐按分类分区展示、当前权限、侧栏权限卡 |
| `admin-pay-setting.png` | 后台「购买套餐设置」：通用设置 + 支付宝当面付/易支付标签页 |
| `admin-plan-list.png` | 后台套餐列表：分类、每日数量、单文件大小、有效期、上下架 |

新增截图时，把图片放进本目录，再在 README.md 里用 `![说明](img/文件名.png)` 引用。
建议统一用 PNG，宽度 1400px 左右，太大的话可以先压缩一下。
